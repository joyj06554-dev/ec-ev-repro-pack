# Selection and screening status

This study workflow documents a **database refinement step**, not a retrospectively reconstructed manual title/abstract or full-text screening stage.

The sequence was:

1. WoS search sets #1 and #2 were combined (#3), yielding 5,367 records.
2. A single combined WoS refinement query (#4) restricted results to:
   - document type: Article or Review;
   - publication year: 2004–2025;
   - language: English.
3. Applying #4 to #3 yielded the final 4,974 records (#5).

Thus, 393 records were removed by the combined database refinement. The original 5,367-record pre-refinement export was not retained, so neither the identities of those 393 records nor criterion-specific exclusion counts can be reconstructed reliably.

No manual screening log is included because no post-#5 manual title/abstract/full-text exclusion stage is documented in the supplied study workflow. This repository intentionally does not fabricate such a log.

# License selection required before public release

No reuse license is imposed by this generated package because license choice is an author/legal decision.

A common approach is to consider:
- a permissive software license for original scripts; and
- an open-content/data license for original documentation and author-generated derived tables,

while excluding third-party database content from any rights grant that the authors do not control.

Before publishing the GitHub/Zenodo record, choose and add the appropriate formal license file(s) and ensure that the Zenodo rights/license field matches the repository.

# Manuscript-ready reproducibility statement

A reproducibility package was prepared to preserve the study's retrieval and analytical provenance. The Web of Science Core Collection search was performed on 10 June 2025. Search sets #1 and #2 retrieved 255,638 and 71,178 records, respectively, and their intersection (#3) yielded 5,367 records. A single database refinement query (#4) limited records to Articles or Reviews published in English from 2004 through 2025. Applying #4 to #3 yielded 4,974 records (#5), which constituted the final bibliometric and altmetric dataset. The 393-record reduction represents a combined database refinement rather than a reconstructed manual screening stage. Because the pre-refinement 5,367-record export was not retained, criterion-specific and record-level exclusion provenance cannot be recovered. The archived package therefore preserves the exact query strings, historical result counts, final-record index, keyword dictionary, analysis metadata, software versions, validation scripts and cryptographic checksums, while explicitly identifying information that was not retained.

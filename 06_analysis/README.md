# Analysis and validation scripts

The scripts in this release are **reproducibility/audit scripts**, not a claim that every published visualization was originally generated by these scripts.

- `validate_wos_dataset.py`: validates record count, identifiers, DOI duplication, document class, languages and source count.
- `build_public_record_index.py`: regenerates the minimized public record index from an authorized folder of WoS plain-text exports.
- `build_keyword_dictionary.py`: regenerates the raw author-keyword frequency dictionary from the WoS `DE` field.

Example:

```bash
python 06_analysis/scripts/validate_wos_dataset.py /path/to/private_wos_exports
python 06_analysis/scripts/build_public_record_index.py /path/to/private_wos_exports public_record_index.csv
python 06_analysis/scripts/build_keyword_dictionary.py /path/to/private_wos_exports keyword_dictionary_raw.csv
```

These scripts use the Python standard library only.

GUI/software analyses reported in the study (e.g., VOSviewer, CiteSpace, HistCite Pro) should be interpreted together with `parameters/analysis_parameters.yaml` and `parameters/software_versions.txt`. Parameters not preserved in the supplied study materials are explicitly marked as not retained rather than reconstructed.
